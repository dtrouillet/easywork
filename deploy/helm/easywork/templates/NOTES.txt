⚠ KNOWN GAP — search indexing (ADR-0004, docs/adr/0004-cross-pod-event-delivery-via-amqp.md):
  DocumentReadyEvent (search-service's input) is still delivered in-process
  only, not over AMQP. Because search-service runs as a SEPARATE pod from
  doc-service, this means newly-ready documents currently do NOT get indexed
  into Meilisearch — search results will silently go stale. This is a known,
  tracked application-level gap, not something this chart can work around.
  Fix upstream (externalize DocumentReadyEvent, mirroring the fix already
  applied to DocumentUploadedEvent/IngestCompletedEvent) before relying on
  search in a multi-pod deployment.

{{- if .Values.minio.enabled }}

⚠ MinIO dependency risk:
  MinIO Inc. archived the open-source MinIO project in 2026 — there is no
  actively-developed upstream to move to. This chart's minio dependency
  (CloudPirates) is pinned to the last pre-archival release
  (2025-10-15); only the base-image/OS layer receives further patches, not
  MinIO application code itself. It also has no distributed/erasure-coded
  HA mode — object-storage durability comes entirely from your
  minio.persistence.storageClass. Review this risk before relying on it for
  production data. See values.yaml's comments and the chart README for
  details.
{{- end }}
